==== USER CONTEXT ==== 

With emulator on Interpreter mode and default RAM size (2MB) I loaded the game and when on the main-menu I injected the script.

The LOAD went normally, first showing a modal with a yellow text "LOAD?" and white options "YES" and "NO". After selecting "YES" it changed to "ACCESSING MEMORY CARD" / "DO NOT PLUG/UNPLUG MEMORY CARD IN MEMORY CARD slot 1". The "ACCESSING" part switched to "LOADING..." and then the whole model became "LOAD COMPLETE!".

The SAVE went normally too. First showing a modal with text a yellow text "SAVE?" and white options "YES" and "NO". The same "ACCESSING..." modal showed afterwards and another modal showed the "OVERWRITE?" with options "YES" and "NO" (all text white). Then the modal became "SAVING..." / "DO NOT PLUG/UNPLUG MEMORY CARD IN MEMORY CARD slot 1", ending with "SAVE COMPLETE!".

At this point I did a soft-reset but the script printed because of a "callback_error".
