==== USER CONTEXT ==== 

With the emulator in Interpret mode and the game loaded on the main-menu I injected the script. Then I did a "Soft-Reset" and a bunch of "UNEXPECTED" writes were printed. It was roughly at vs=576 that the screen cleared to black and around vs=635 that the Konami logged showed up.

The game booted normally and I loaded a save file and went to the campaign. I started in the card shop, left it and went to the palace to duel "Simon Muran". After defeating Simon I went back to the "Card Shop" and chose the "RETURN TO TITLE" option to bring me back to the main menu. There I changed the memory position 80184594 to 0B and pressed enter, loading the Debug Menu.

It was around vs=12607 that I pressed the "BustUp" option. It made a dialog box show on the bottom of the screen (behind the debug menu) and with no text. I waited a bit and then went to the "MOVIE" option and selected it. The game stopped responding to my input but according to the emulator it was still rendering normally. No movie played and I just waited for the trace to be printed.

 
The change noted at vs=2179 happened during the black screen loading the campaign.
The change noted at vs=1201 happened during the black screen loading the debug menu.
