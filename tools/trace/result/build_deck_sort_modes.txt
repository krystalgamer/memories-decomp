==== USER CONTEXT ==== 
 
For "Chest" there's 8 sort modes:
- card id - top card is lowest id
- alphabetical - top one is A
- strongest attribute of max(atk,def) - top one if highest max attribute
- atk - top is highest atk
- def - top is highest def
- type - by card type (starts with spellcaster)
- new card - newest card on top

For "Deck" there's 8 and changes "new card" with "shuffle" and has the name implies it's a random order.
I did one full cycle in "Chest" card id -> ... -> card id and then moved to "deck" and I almost did two cycles. On the second cycle when going from strongest to atk it printed the trace.
