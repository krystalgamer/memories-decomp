**The switch dispatch needs four separate case bodies, not two shared ones.**
Written the natural way -

```c
case 0x44:
case 0x45:
    ...body A...
    break;
case 0x29:
case 0x2A:
    ...body B...
    break;
```

GCC merges each adjacent pair into a *case range* and emits range tests -
`slti $v0,$a0,41`, `slti $v0,$a0,43`, `slti $v0,$a0,70`. The target instead
tests equality against 0x44, splits at 0x45, and then tests 0x29 and 0x2A
individually, which is what GCC emits when it sees four separate single-value
case nodes. Duplicating the body under each label produces exactly that, and
cross-jumping then merges the identical bodies again so the instruction count is
unchanged. Worth 58 positions on its own, 131 down to 73. **Adjacent case
values that share a body are not free: the merge into a range changes the
dispatch shape.**

move with zero displacements; an eight-word type gets the target's unrolled
`lw`/`sw` pairs at immediate offsets. 73 down to 69.
