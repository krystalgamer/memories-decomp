The model animation switch, next to `func_800577B0`. With `anim == -1`
it clears the pending flag and marks every attached part's frame
(+8 in the part record) as 0xFFFF. With `anim == 0` it flushes the
current animation: for every part whose map entry for the current
animation is valid it copies three or five words (five when the part's
bit in the +0xBEC mask is set) from the animation data at +0xDDC into
the frame buffer at +0xDE0. Any other animation is selected: the mode
byte is set to 2 unless it is the slot's default animation, a zero-length
entry is refused, a running animation is flushed first (only when the
flag argument allows it), mode 7 is set for the default or the 0x309
model, the current animation is recorded, a re-selection just re-queues
through `func_800597C8`, and otherwise the pending flag is raised and
every part gets its frame index and its first frame copied in.

**What the shape needed.**

- *The three cases are a `switch` on the animation* (cases -1 and 0,
  then default), which gives the two `beq`/`beqz` dispatch tests and the
  jump to the default block.
- *A slot struct with every field the function touches* (parts table,
  animation map as `u16 [11][58]`, entries, bit mask, the three pointers
  and the state bytes), so every access is off the one slot register;
  casting the pointer per access makes the loop optimizer hoist the cast
  as an invariant into a second register.
- *The bit test is written as the manual signed divide:* `t = i; if (i <
  0) t = i + 7; count = 3; t >>= count;` and `i - (t << count)`. Written
  as `i / 8` and `i % 8` the shifts are immediates; retail shifts by the
  register that holds the word count, which cse only produces when the
  count is assigned in the join block after the sign adjust.
- *The part walks step the pointer* (`parts++`) with the pointer
  increment before the counter increment in the `for` header, which puts
  the counter increment in the count load's delay slot; the other order
  hoists it into the part load's delay slot and costs a `nop`.
- *The map entry is read before the 0xFFFF test with its source address
  computed from it,* as retail does even for skipped entries.

**Where the residual is.** Global allocation orders the word count

the count and shift as one or two variables, the bit test through
